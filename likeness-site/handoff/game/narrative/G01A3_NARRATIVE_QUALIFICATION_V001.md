Authority: OVS Dialogue Naturalism Law V001, OVS-OS `codex/ovs-dialogue-naturalism-law-v001` @ `2711c91`. Pipeline steps 6–10: human read-aloud, then independent cold read, then repair and re-read, then founder review, then promotion.

| Step | Who | Input | Output (real evidence only) |
|---|---|---|---|
| CR-0 Prep | Coordinator (not a reader) | The 28 provisional utterances, exported as one script per character (§3 template), each with node ID, speaker, preceding-route context and the facts the speaker is allowed to know | Script files + SHA-256 |

**Actor-performance approval** is granted only after CR-1 and CR-2 contain real human observations for the exact final text. Self-assessment by an AI system is not evidence (Dialogue Law §4).

## 4. Evaluation rubric

Scores are 0–2 per criterion: 0 = fails, 1 = playable with a note, 2 = passes. A line passes when no criterion scores 0 and the total is at least 11 of 14.

| # | Criterion | Dialogue Law reference | 0 looks like |
|---|---|---|---|
| R-1 | Objective | §1 "speaks to change a situation…" | The line explains rather than pursues something |
| R-2 | Character-specific voice | §1 REQUIRE; survives name removal | The cold reader cannot tell Thoreau from Drya with names hidden |
| R-3 | No corrective antithesis or epigram | §1 REJECT | "It wasn't X. It was Y."; a tagline-ready aphorism |
| R-4 | No thesis or lore exposition | §1 REJECT | The character narrates the theme, the tape's rules or their own psychology |
| R-5 | Knowledge-legal | W01 rule; §6 below | The line references a fact the speaker cannot know on some incoming route |
| R-6 | Route continuity | Bible §17 Convergence Continuity | At a convergence, the line ignores the route the player actually took |
| R-7 | Playability | §1 "director/actor can stage…" | The reader cannot perform it without adding narration |

**Game-specific authority vs SECOND HAND film authority.**
- Game lines are judged only against LIKENESS : THE GAME sources: Production Bible V001, Tape 03 Bible V.002 and the GL-16 story draft once signed.
- The SECOND HAND film's SH-G07 and SH-STORY-G08 restrictions (Dialogue Law §2) apply only where a G01A.2 line explicitly reuses SECOND HAND material. A reviewer must cite which authority a defect is filed under, and must not import film voice decisions into game characters by default.

## 6. W01 dialogue conditioning — the rule and its enforcement

**Rule.** A character may only acknowledge a fact that is known on every route that reaches the line. Something the player has seen elsewhere (in the companion archive, in another playthrough's discovery history, or on a route not taken) does not count.

Enforcement in this gate:

| Mechanism | Where | Proof |
|---|---|---|
| Facts are run state, set by effects; discovery history is a separate ledger and never feeds conditions | `engine/narrative-engine.mjs` (`facts`, `recordDiscovery`) | Test "separate playthroughs" |
| Static check: `acknowledges[]` must be in the intersection of known facts over all incoming paths | `validateGraph()` | Test "W01 conditioning": W01 acknowledging `app_shows_unplayed_node` is flagged |
| Runtime check: lines that mention a fact carry `requires: {fact: …}` and are not offered otherwise | `availableChoices()` / adapter spec §8 | Spec §8 |
| The companion projection shows undiscovered nodes as `???` or omits them, so the archive a player opens at W01 cannot leak a label for a character to react to | `projectForCompanion()` | Unit test + real-browser test "spoiler control" |

**Correcting G01A.2's actual W01 line is blocked** until its text is available. The correction procedure:
1. list the facts W01's line references;
2. for each fact not set before W01 on every route, either remove the reference or move the line behind the node that sets the fact;
3. re-run the validator and expect zero W01 warnings.
