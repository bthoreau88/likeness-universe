existing character/location/asset IDs, approved image authorities, deliverable,
reference inputs, and QC criteria. Adapt the chosen prompt to the current provider
and acceptance target; old model names/settings are historical recipe labels.

descriptions; an attractive generated face is not identity evidence. Preserve
natural skin, accessories, proportions and asymmetry. Separate character-reference
lighting from the cinematic grade. Continue the four-stage reference workflow for

existing prompt-library module according to their current roles, never a PDF blob
hardcoded into a component. No automatic PDF-to-runtime import is implemented.
